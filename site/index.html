A kit for game developers.

For developers with nobody to test a build. Your game ships with controls an AI coding tool can use to play and test it.

These controls are MCP tool calls, a common way for an AI coding tool to use another program. You write the game.

How the kit works

  • Orange: you play a game yourself
  • Pink: a program plays it with tool calls

What a game maker does with the kit

  1. Write the rules. Your game is plain data, a list of legal moves and one step function. The kit gives it every screen: title, levels, settings, pause and results.
  2. Prove each level. The prover searches every level and saves a proof that it can be finished. It uses no AI model.
  3. Let a tool play. An AI coding tool connects to your game with MCP and plays it with the five tool calls while it writes the code.
  4. Check a replay. A replay is a seed and a list of moves. It always ends in the same state, so a bug found once can be played again.
